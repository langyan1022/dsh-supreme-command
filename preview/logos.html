02 / STILL

静态终态data-mode="still"

动画全部落到终态：animation:none，叶子 opacity 1、clip-path ins(0)、描边 offset 0、填充实心。

BSC · data-mode="still"

STATIC MODE

终态在 CSS 里显式声明，不依赖动画的 forwards 填充，首屏/Print/缩略图都不会出现半截。

<!-- 容器上加 data-mode -->
<div class="dsc-bsc" data-mode="still">…
/* 系统减少动态效果时，媒体查询自动等同 still */
@media (prefers-reduced-motion: reduce) { … }
